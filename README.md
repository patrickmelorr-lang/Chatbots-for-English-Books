#  Chatbots-for-English-Books

Traducción de libros inglés → español y chatbot tipo ChatGPT para estudio académico.

##  ¿Qué hace este proyecto?

- Traduce libros completos del inglés al español
- Crea un chatbot con RAG (Retrieval-Augmented Generation)
- Permite hacer preguntas sobre el libro traducido

##  Tecnologías

- Python 3.10
- OpenAI API
- RAG (LangChain o similar)
- Jupyter Notebooks
